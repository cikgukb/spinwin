# 🎰 Spin & Win System - KB Beyond

Sistem Spin & Win interaktif dengan interface moden dan menarik.

## ✨ Ciri-ciri

- 🎨 **Interface Eye Candy** - Design premium dengan tema Emas & Ungu
- 📝 **Borang Pendaftaran** - Nama, No Telefon, Email
- 🎡 **Roda Spin & Win** - Animasi spinning yang smooth
- 🎁 **8 Jenis Hadiah** - Dengan kebarangkalian berbeza
- 🔄 **Cuba Lagi Logic** - Boleh spin semula jika tidak menang

## 🚀 Cara Guna

1. Buka `index.html` dalam browser
2. Isi borang pendaftaran
3. Klik "Teruskan untuk SPIN!"
4. Tekan butang SPIN di tengah roda
5. Lihat hadiah anda!
